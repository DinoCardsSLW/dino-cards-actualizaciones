# Dino Cards · Actualizaciones

Aquí se publican las versiones del programa de punto de venta **Dino Cards** para Windows.
El programa revisa este repositorio solo (al abrir y cada 6 horas), descarga la versión nueva
y **verifica su firma** antes de instalarla. No contiene código ni datos de la tienda.

- `ultima.json`: la versión más reciente y sus novedades.
- `versiones/`: los instaladores firmados (se conservan las 3 más recientes).
- `NOVEDADES.md`: historial de cambios.

Para instalar a mano, descarga el `.exe` más reciente de `versiones/`.
